# TraceDesk 线稿描绘台

面向单色线稿的人工单线矢量描绘工作区。首页管理底图与可编辑折线，图像准备工作区提供独立的图像处理流程。

启动：`docker compose -p solo36-tracedesk up -d --build`，浏览器打开 http://127.0.0.1:18936/ 。`TRACE_DATA_DIR`可指定数据目录，默认data；容器持久化在/data。

## 描绘工作流

新建图稿，生成合成线稿或上传PNG/JPEG，设为底图；开始新路径后逐点点击，完成即保存。可选闭合，支持节点坐标编辑/删除、路径平移、反向、复制、重命名、删除，独立撤销重做和图稿复制。背景透明度、输出线宽与线色可调。导出PNG/SVG不含底图；工程ZIP含JSON、矢量、PNG与原素材。ZIP中的drawing.json可在原素材仍存在的本工作区导入。

## 徽记过渡（第三版）

在右侧「徽记过渡」选择两条 3–12 节点、节点数相同的闭合路径，可生成旧版到新版 25%、50%、75% 三张中间稿预览。配法只允许对换一圈的起笔角或整体反向（共 2n 种），不拆散环上不相邻的角；对应角在同一进度线性插值。三张中间稿都必须保持简单闭环：不允许边相交、非相邻边相碰或两个角挤成一点。合格配法先压低被拉得最远角的移动量，再压低所有角总移动量。找不到合格配法会直接说明且不改动图稿。任一中间稿可另存为普通闭合可编辑路径，原两条路径保持可编辑，一次撤销即可移除新增路径；原路径被编辑或撤销后预览自动失效，需要重新生成。不提供动画导出。

## 图像准备

/prepare提供图片导入、曝光与色彩调整、几何配准、融合、局部遮罩、区域统计、前后对照、质量图、批处理预检、项目归档和常规图像导出；采用独立prepare数据目录。

## 范围

底图最长边2048px、上传12MB；每稿最多500路径，每路径2至4096节点。画布使用原图像素坐标。已有描线的图稿不能改成不同尺寸的底图。撤销历史最多30步。合成示例已标记SYNTHETIC，不是真实观测。当前提供人工描线，不识别字符、不自动猜测笔顺，也不保证物理绘图机的走笔顺序。SVG为开/闭折线路径、圆角连接，矢量透明背景；PNG为白色底板。没有性能规模承诺。
