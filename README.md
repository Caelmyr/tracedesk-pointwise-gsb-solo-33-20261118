# TraceDesk 线稿描绘台

面向单色线稿的人工单线矢量描绘工作区。首页管理底图与可编辑折线，图像准备工作区提供独立的图像处理流程。

启动：`docker compose -p solo36-tracedesk up -d --build`，浏览器打开 http://127.0.0.1:18936/ 。`TRACE_DATA_DIR`可指定数据目录，默认data；容器持久化在/data。

## 描绘工作流

新建图稿，生成合成线稿或上传PNG/JPEG，设为底图；开始新路径后逐点点击，完成即保存。可选闭合，支持节点坐标编辑/删除、路径平移、反向、复制、重命名、删除，独立撤销重做和图稿复制。背景透明度、输出线宽与线色可调。导出PNG/SVG不含底图；工程ZIP含JSON、矢量、PNG与原素材。ZIP中的drawing.json可在原素材仍存在的本工作区导入。

## 自动转单线

画布工具栏的「自动转单线」面向最长边不超过256像素、笔画约3至15像素宽的干净不透明单色线稿（不识字、不猜笔顺、不处理复杂噪声）。先拖动黑白阈值并在浮层查看二值化结果，确认实际要处理的笔画；服务端对笔画掩膜做Zhang-Suen细化取中线，再把骨架拆成与手工描线同构的可编辑路径：粗线只生成一根中线（不把两侧轮廓当两根线），交叉与分叉拆成多条在同一节点相接的路径，闭环真闭合，彼此分离的线团保持独立。

提供两种取向：**忠实**保留线网的分叉、短末梢与闭环；**简洁**允许删除中线长度不超过3像素的末梢，并用更少节点表示剩余线条（相对忠实结果偏移不超过2像素），但仍保留每个独立线团与全部闭环，小闭环不会被当作短末梢删除。预览以紫色路径叠在底图上，简洁模式删除的末梢用红色虚线标出，可对照看出差异；预览不落库，底图或路径一经修改旧预览即失效。采纳后才替换当前描线，且只产生一个撤销检查点，一次撤销即可恢复原来的全部路径；丢弃则不改变任何已有描线。生成的路径沿用现有节点编辑、PNG、SVG与工程ZIP导出，刷新选回图稿后可继续修改，原有人工描线功能不变。

## 图像准备

/prepare提供图片导入、曝光与色彩调整、几何配准、融合、局部遮罩、区域统计、前后对照、质量图、批处理预检、项目归档和常规图像导出；采用独立prepare数据目录。

## 范围

底图最长边2048px、上传12MB；每稿最多500路径，每路径2至4096节点。画布使用原图像素坐标。已有描线的图稿不能改成不同尺寸的底图。撤销历史最多30步。自动转单线仅支持最长边不超过256像素、笔画约3至15像素宽的干净不透明线稿，识别结果同样受500路径/4096节点上限约束。合成示例已标记SYNTHETIC，不是真实观测。人工描线不识别字符、不猜测笔顺；自动转单线只做笔画中线提取，不识字、不猜笔顺，也不保证物理绘图机的走笔顺序。SVG为开/闭折线路径、圆角连接，矢量透明背景；PNG为白色底板。没有性能规模承诺。
